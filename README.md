# English 30

Полчаса английского в день для уровня A1–A2: грамматика, слова, правописание, говорение.
Объяснения по-русски, материал по-английски. Одно занятие = 5 блоков по 4–8 минут.

## Запуск

Открыть `index.html` в Chrome или Edge (двойной щелчок по файлу). В этих браузерах работают
и озвучка, и распознавание речи для блока «Говорение». В Firefox распознавания нет —
говорение переключается на самооценку.

На телефоне: скопировать `index.html` в память телефона и открыть в Chrome (Android) или
Safari (iPhone), либо открыть опубликованную ссылку.

Прогресс хранится в браузере. Перенос на другое устройство — в разделе «Ещё»: файлом или кодом.

## Установка на планшет или телефон (PWA)

Сайт: **https://drunkmay79.github.io/english30/**

Открыть ссылку в Chrome на Android → меню ⋮ → «Установить приложение» (или «Добавить на главный
экран»). Дальше приложение запускается с иконки, на весь экран и без интернета. На iPhone:
Safari → «Поделиться» → «На экран „Домой“».

## Сборка и публикация

```bash
python tools/make_icons.py   # иконки в public/icons (нужен Pillow)
python build.py              # index.html, artifact.html и папка dist/
npm run deploy               # сборка + публикация dist/ в ветку gh-pages
```

Исходники — в `src/`, порядок склейки задан в `build.py`; подпапка сайта (`/english30/`) — константа
`BASE` там же, она же подставляется в `start_url` и `scope` манифеста. Service worker (`src/sw.js`)
получает версию при сборке: новая публикация → новый кеш, страница перезагружается сама один раз.
Методика, содержание и устройство описаны в [МЕТОДИКА.md](МЕТОДИКА.md).
