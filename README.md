# English 30

Полчаса английского в день для уровня A1–A2: грамматика, слова, правописание, говорение.
Объяснения по-русски, материал по-английски. Одно занятие = 5 блоков по 4–8 минут.

## Запуск

Открыть `index.html` в Chrome или Edge (двойной щелчок по файлу). В этих браузерах работают
и озвучка, и распознавание речи для блока «Говорение». В Firefox распознавания нет —
говорение переключается на самооценку.

На телефоне: скопировать `index.html` в память телефона и открыть в Chrome (Android) или
Safari (iPhone), либо открыть опубликованную ссылку.

Прогресс хранится в браузере. Перенос на другое устройство — в разделе «Ещё»: файлом или кодом.

## Сборка после правок

```bash
python build.py
```

Исходники — в `src/`, порядок склейки задан в `build.py`. Методика, содержание и устройство
описаны в [МЕТОДИКА.md](МЕТОДИКА.md), список задач — в `work/ЗАДАЧИ.md`.
