# English 30 — методика и устройство приложения

Приложение для самостоятельного изучения английского на уровне A1–A2 по 30 минут в день.
Интерфейс и объяснения — по-русски, весь учебный материал — по-английски. Один HTML-файл,
работает в браузере на компьютере и телефоне, без установки и интернета (кроме распознавания речи).

Дата: 13.10.2026.

---

## 1. Анализ методов: что работает по данным науки и как это реализовано

| Метод | Что известно | Как реализовано в приложении |
|---|---|---|
| **Интервальное повторение** (Эббингауз; Cepeda и др., 2006; алгоритмы SM-2 / FSRS) | Повторение с растущими интервалами даёт в 2–3 раза более прочную память, чем зубрёжка подряд | Каждое слово и фраза — карточка. Верный ответ отодвигает показ: 1 → 3 → 7 → ~15 → ~35 дней; ошибка возвращает на сегодня и снижает «лёгкость». Блок «Повторение» открывает каждое занятие |
| **Активное вспоминание** (testing effect; Roediger & Karpicke, 2006) | Попытка вспомнить закрепляет лучше, чем повторное чтение | Правило читается один раз, дальше — только задания. 19 типов упражнений, ни одного «просто прочитай» |
| **Чередование** (interleaving; Rohrer, 2012) | Смешанные темы запоминаются лучше, чем блоками одной темы | Пять блоков разных навыков за занятие; в блок грамматики вкраплены задания из прошлых, самых слабых тем |
| **Желательные трудности и лестница сложности** (Bjork) | Усилие при вспоминании полезно, если посильно | Карточка проходит этапы: узнать (выбор из 4) → вспомнить (напечатать) → использовать (сказать, перевести). Тип задания выбирается по этапу |
| **Немедленная обратная связь и обучение на ошибках** | Исправление сразу после ошибки + объяснение «почему» закрепляет правило | После ошибки — правильный ответ с озвучкой, пояснение, и то же задание возвращается через 4 шага. Опечатка (1–2 буквы) засчитывается как «почти» |
| **Двойное кодирование** (Paivio) | Образ + слово запоминаются лучше, чем слово | Каждое слово: картинка-эмодзи + звук + пример в контексте + перевод |
| **Лексический подход, chunks** (Lewis) | Носители говорят готовыми блоками, а не собирают из слов | 88 фраз-кирпичей («How much is it?», «I'd like…») учатся целиком, в диалогах и говорении |
| **Понятный ввод i+1** (Krashen) | Понимание текста, где 95 % слов знакомы, а 5 % — новые | 8 текстов и 12 диалогов из лексики приложения; чтение раз в три занятия |
| **Выход и эффект произнесения** (Swain; MacLeod, production effect) | Сказанное вслух запоминается лучше прочитанного про себя | Блок «Говорение» каждый день: повтор за диктором (shadowing), ответ по-русски → вслух по-английски, диалог с распознаванием речи |
| **Замечание формы** (noticing; Schmidt) | Чтобы усвоить структуру, её надо заметить | Цветные блоки «кто — действие — остальное», шкала времени, задание «найди ошибку» |
| **Когнитивная нагрузка** (Sweller) | Одно правило за раз, короткие блоки | Один юнит = одно правило + одна таблица. Блоки по 4–8 минут |
| **Microlearning и привычка** (Fogg; Duolingo-исследования о серии дней) | Регулярность важнее длительности | Цель в минутах, серия дней, план занятия виден заранее, штрафов нет |
| **Mastery learning** (Bloom) | Переход дальше — при освоении, а не по календарю | Следующая тема открывается при точности ≥75 % (минимум два занятия); тема возвращается, если точность упала ниже 50 % |

## 2. Варианты, которые рассматривались

**Структура занятия.**
A) Один сплошной поток заданий (как Duolingo) — просто, но навыки смешиваются неуправляемо.
B) **Пять блоков по навыкам, конечный список заданий (выбрано с 12.11.2026)** — повторение → грамматика → слова → правописание → говорение (+ чтение раз в три дня). Список заданий составляется заранее и рассчитан примерно на 30 минут; таймера нет. До 12.11.2026 у блоков были таймеры, и когда задания кончались раньше времени, блок добирал новые из того же материала — ученица воспринимала это как повтор одного и того же и искусственное затягивание. От таймеров отказались.
C) Полностью свободный выбор — для A1 слишком много решений; оставлен как раздел «Практика».

**Повторение.**
A) Коробки Лейтнера — грубо. B) **SM-2 с лестницей этапов (выбрано)** — проверенный, прозрачный. C) FSRS — точнее, но требует обучения параметров; разумное развитие.

**Проверка речи.**
A) Самооценка. B) **Web Speech API браузера (выбрано)**: Chrome/Edge/Safari распознают английский бесплатно; ответ сравнивается по словам с подсветкой расхождений. Если распознавания нет (Firefox) — автоматически вариант A. C) Серверный Whisper / ИИ-собеседник — следующий шаг.

**Образность.**
A) Фотографии — лицензии, вес файла, долгий отбор. B) **Эмодзи (выбрано)** — 0 КБ, 491 слово с картинкой сразу. C) Генерация картинок — позже.

**Хранение.** A) **localStorage + экспорт файлом/кодом (выбрано)** — приватно, офлайн. B) Аккаунт и облако — не нужны для одного пользователя.

**Формат.** **Один HTML-файл (выбрано)**: открывается двойным щелчком, кладётся на телефон, публикуется как artifact или на GitHub Pages.

## 4. Конструкция приложения

```
C:\English\
  build.py            сборка одного файла: python build.py → index.html
  index.html          готовое приложение (открывать в Chrome / Edge / Safari)
  src\shell.html      каркас страницы
  src\styles.css      стили: светлая и тёмная тема, мобильная вёрстка
  src\data\grammar1-3.js   40 тем грамматики (правило HTML, формула-блоки, примеры, упражнения)
  src\data\vocab1-2.js     20 тем лексики
  src\data\chunks.js       фразы, диалоги, тексты
  src\core.js         утилиты, нормализация текста, хранилище, профили, SRS, генераторы, планировщик, речь
  src\exercises.js    рендеры 19 типов упражнений + урок/напоминание
  src\app.js          экраны (Сегодня, Практика, Прогресс, Ещё), раннер занятия, онбординг
  work\ЗАДАЧИ.md      живой список задач
```

**Занятие** — конечный список заданий, который планировщик (`Planner.build`) составляет один раз на день и хранит в профиле: можно закрыть и продолжить с того же места. На главном экране виден план: блоки, число заданий и примерное время каждого.

Как распределяется время (для занятия 30 минут, при другой длине всё масштабируется):
- **Повторение** — по числу карточек, которые пора вспомнить: 22 с на карточку, от 2,5 до 8 минут. Если долг по повторению больше 25 карточек, новых слов в этот день меньше.
- **Слова** — до 7 минут: число новых слов подбирается так, чтобы уложиться (максимум: лёгкий 5, обычный 6, сложный 8).
- **Правописание** и **говорение** — фиксированный набор; диалог через день.
- **Грамматика** — оставшееся время, не меньше 5 минут. Урок нового правила засчитывается в бюджет не больше чем на 90 секунд, чтобы новой теме хватало упражнений.

Оценка времени задания — таблица `EST` (выбор 15 с, впиши 22 с, собери 35 с, перевод 45 с, диалог 150 с…). После каждого задания реальное время записывается в `P.pace` (скользящее среднее), и следующие планы строятся по темпу ученика.

**Без повторов внутри занятия.** Каждое слово и фраза попадает только в один блок. Предложения сверяются по тексту на всё занятие (`Planner.sentKey`): пример из правила, предложение из упражнения или пример к слову встречаются один раз. Внутри темы упражнения выбираются по принципу «что показывалось реже» (счётчик `units[id].sh`), поэтому на второй день темы идут другие упражнения. Возвращается только задание с ошибкой, не больше трёх на блок.

**Сложность** (`Planner.level`): лёгкая / обычная / сложная или «авто». Авто смотрит на точность последних шести дней: от 88 % — сложная, ниже 62 % — лёгкая, с запасом против скачков (сложная держится до 78 %). Что меняется на сложном уровне:
- карточки повторения получают задание на ступень выше (меньше выбора, больше письма);
- в грамматике не больше трёх заданий с выбором ответа, добавляются сборки предложений из примеров с лишним словом-ловушкой и задания «какое время?» (`Gen.mix`: usually → Present Simple, now → Continuous, yesterday → Past), когда пройдены хотя бы два времени;
- больше вкраплений из прошлых тем, в них только задания с письмом;
- в словах — до 8 новых слов, письмо вместо выбора, предложения с новыми словами, перевод фраз вместо выбора;
- во «вставь буквы» скрыто 65 % букв вместо 40–50 %; в правописании два диктанта предложений;
- в говорении больше перевода вслух, меньше простого повтора.

**Отчёт папе** (`src/report.js`). Оценка недели по пятибалльной шкале — среднее трёх частей:
- регулярность — дни с занятиями за 7 дней (день считается, если было ≥ 5 минут или ≥ 10 заданий): 6–7 → 5, 5 → 4, 3–4 → 3, меньше → 2;
- точность с первой попытки за неделю: ≥ 90 / 80 / 65 % → 5 / 4 / 3 (на сложном уровне пороги на 5 % ниже);
- проверка без подсказок — 10 случайных заданий по выученному (4 слова письменно, 2 диктанта, 4 грамматики), опечатка — полбалла: ≥ 90 / 75 / 55 % → 5 / 4 / 3. Проверка не меняет прогресс; номер попытки за день попадает в отчёт.

Данные отчёта упаковываются в ссылку `…/en30/#r=…`: JSON → deflate (`CompressionStream`) → base64url. С 12.11.2026 (формат v2) отчёт полный, за всё время: 14 последних дней по дням, вся история по неделям, все 40 тем грамматики, слова по темам, история проверок, трудные слова и ответы последней проверки за неделю. Ссылка за 200 дней занятий — около 1300 символов, сообщение в Telegram — около 1500 (предел Telegram 4096). Ссылки старого формата v1 тоже открываются. На планшете тот же отчёт открывается кнопкой «Полный отчёт» («Прогресс» и «Ещё»). На сервер ничего не уходит; по ссылке страница отчёта открывается без профиля и ничего не сохраняет.

Два способа доставки:
- **вручную** — «Отчёт папе»: проверка, затем меню «Поделиться» (Telegram, WhatsApp, СМС) или копирование ссылки;
- **автоматически** — «Ещё → Автоотправка в Telegram». Папа создаёт своего бота у @BotFather и вводит токен на планшете; токен хранится только в памяти устройства (ключ `en30_auto`), не в профиле, не в коде переноса и не в репозитории. После каждого законченного занятия уходит короткое сообщение; раз в 7 дней в занятие добавляется блок «Проверка для папы», и после занятия уходит отчёт со ссылкой. В день проверки блок слов короче и без диалога, чтобы занятие не удлинялось. Без интернета сообщения ждут в очереди (`en30_outbox`) и уходят при подключении. Настройки можно закрыть ПИН-кодом.

Запросы к Telegram — «простые» (form-urlencoded): на JSON браузер делает предварительный запрос OPTIONS, а Telegram отвечает на него 501, и браузер блокирует отправку (проверено 12.11.2026).

**Профиль** — `localStorage` с префиксом `en30_`; несколько профилей; перенос файлом JSON или base64-кодом.

**SRS** (`SRS.grade`): оценки 0 — ошибка, 1 — с подсказкой/опечаткой, 2 — верно, 3 — верно и уверенно. Этапы карточки 0–4. Ограничение интервала 120 дней.

**Освоение темы грамматики** = точность последних 20 ответов × min(1, ответов/N), где N = 10 при точности от 90 % и 14 иначе. Сильный ученик закрывает тему за одно занятие, остальные — за два. Засчитываются только грамматические типы заданий (выбор, впиши, собери, переведи, ошибка). Порог закрытия 75 %, повторного открытия 50 %.

**Сравнение ответов** (`Txt`): регистр, пунктуация и типографские апострофы не важны; сокращения (I'm / I am, isn't / is not, won't / will not…) приравниваются; опечатка в 1 букву при длине ≥ 6 и 2 буквы при ≥ 12 — «почти». Речь сравнивается по словам (наибольшая общая подпоследовательность), совпадение ≥ 85 % — зачёт.

## 5. Как расширять

- **Новая тема грамматики**: добавить объект в `grammar3.js` по образцу (`id`, `title`, `rule`, `blocks`, `ex`, `drills`). Порядок в файле = порядок прохождения.
- **Новая тема слов**: `VOCAB.push({...})` в `vocab2.js`, формат строки `[en, ru, эмодзи, пример EN, пример RU]`.
- **Диалог / текст**: `DIALOGS` и `TEXTS` в `chunks.js`. В диалоге реплики `B` — реплики ученика.
- После правок: `python build.py` и проверка `node --check` для каждого файла.

Идеи следующего этапа: алгоритм FSRS; транскрипция и ударение; настоящие фото для конкретных существительных; ИИ-собеседник для свободного диалога с исправлением ошибок (Claude API); письменные задания с проверкой; PWA-манифест и офлайн-кэш; уведомление-напоминание; публикация на GitHub Pages для ссылки на телефон.

## 6. Что проверено и что нет

Проверено 13.10.2026:
- автотест в браузере: 3744 упражнения (все дриллы, генераторы, 6 типов заданий для каждого из 491 слова, фразы, тексты) отрисованы и решены эталонным ответом — 0 ошибок;
- симуляция 30 дней занятий: планировщик не падает, темп ~1 тема грамматики за 1,5–2 дня, 6 слов в день, блок повторения растёт до 24 карточек;
- экраны: онбординг, главный, урок, выбор, собери, карточка, пары, вставь буквы, говорение, практика, прогресс, настройки — без ошибок в консоли.

**Не проверено живьём**: распознавание речи через реальный микрофон (в тестовой среде микрофона нет), звучание озвучки, работа на iPhone / Android, сохранение прогресса при закрытии браузера на телефоне.
